# 資料來源

| 來源 | 實際用途、涵蓋及品質 |
| --- | --- |
| TDCC 官方 1–5 | 集保週資料，核對 1–17 級、股數、戶數及分母。官方資料授權參照 [政府資料開放平台](https://data.gov.tw/dataset/11452)。歷史備份公布時點須另證。 |
| TWSE／TPEx OpenAPI | 上市櫃名單、單日行情及交易日曆。RC4 CI 名單為 1,092／899，單日行情 1,091／862，來源交易日可能不同。再散布依各來源條款核對。 |
| FinMind | 個股日 K 與股本，採逐股快取。日 K 覆蓋與股本可用時點待驗。快取與共享授權須按服務條款確認。 |
| 手動 CSV | 保留來源，時點待證，不能進嚴格歷史判定。歷史格式及解析缺陷見架構。 |
| 第三方歷史與券商分點 | 研究候選。逐項驗授權、缺期、修訂、單位及涵蓋；未上榜保留缺值，分點為券商通路。 |

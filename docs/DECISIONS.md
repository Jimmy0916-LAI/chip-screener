# 決策

## 已批准

- Windows 11 x64 完整 ZIP，保留 EXE 內部網頁與本機服務。停止獨立 HTML 規劃與驗收，保留舊成品和歷史。
- 產品負責人已授權本輪 A–G 開發、CI、隔離測試資產及經開發端驗證的 Beta 預發行。對外 Beta 通道切換須經獨立審查及產品負責人確認；正式 Stable 和產品程式合併 main 須另獲批准。
- 更新目標只能取官方 repo README 固定格式的唯一 Stable／Beta 下載指標。驗證 Tag、Release、Windows ZIP 與 manifest，格式錯誤時停止。無 Stable 與未指定較高版本均不得自行推定。正式發布和通道切換需產品負責人批准，Beta 發布須當批明確授權。
- 發行 manifest 至少含 schema、版本、來源提交、架構、完整包資產名稱、大小、SHA-256 與資料相容性。發行流程另產出版本資訊與 SHA256SUMS。
- 資料中心以 chip-screener-data 與 chip-screener-data-2026 建立骨架。可公開非敏感索引與具轉發授權的資料。一般使用者網路優先、預設不永久保存市場資料，取代 Skill v1.0 的一般使用者磁碟快取預設。舊資料保留。詳見[產品規格](../PRODUCT_SPEC.md)。
